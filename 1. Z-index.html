CSS Z-Index Demonstration

The element with the highest z-index appears on top.

Red Box
z-index: 1
Blue Box
z-index: 2
Green Box
z-index: 3

How z-index Works

The three boxes overlap each other. Their stacking order is determined by their z-index values.

Red Box → z-index: 1

Blue Box → z-index: 2

Green Box → z-index: 3

Therefore, the green box appears on top because it has the highest z-index value.
