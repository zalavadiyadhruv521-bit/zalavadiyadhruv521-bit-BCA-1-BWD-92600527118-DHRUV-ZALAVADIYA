How Z-Index is Used

This image slider demonstrates how z-index controls the stacking order of elements.

Image: The image is at the bottom layer.

Overlay: The dark overlay uses z-index: 1.

Text: The text uses z-index: 2, so it appears above both the image and overlay.

In simple terms:

Image → z-index: 0
Overlay → z-index: 1
Text → z-index: 2
